# ZIGZAG — Neon Arcade

A fast, minimalist browser arcade game built with vanilla HTML, CSS and JavaScript.

## Gameplay

Stay on the narrow path for as long as possible. Click, tap, or press **Space** to switch direction. The pace increases as your score grows.

## Features

- Responsive desktop and mobile gameplay
- Smooth Canvas rendering
- Click, touch and keyboard controls
- Persistent personal best using Local Storage
- Progressive speed
- Minimal neon UI and particle effects
- Optional game sounds
- Zero dependencies and no build step

## Run locally

Open `index.html` in a browser, or serve the directory using any static web server.

## Deploy with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Built as a lightweight front-end game with HTML5 Canvas.
